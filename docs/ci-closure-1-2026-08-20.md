- `postbuild` -> `node scripts/run-pagefind.js && node scripts/build-seo-dashboard.js && npm run check:researchfi-integrity`
- `build:no-og` -> `DISABLE_OG_IMAGES=true npm run eleventy`

Conclusion:

- `staging.yml` duplicated Pagefind by running `npm run build` and then `npm run search:index`
- `build.yml` duplicated Pagefind by running `npm run build:no-og` and then `npm run search:index`

## 6. Evidence by Workflow

### Accessibility and navigation tests

Observed current behavior before change:

- docs-only PRs ran full browser CI
- merged production code ran the same browser suite again on `main`
- this workflow is not the production deployment gate

Change:

- removed `push main`
- kept `pull_request main`
- added `paths-ignore: docs/**`
- kept `workflow_dispatch`

Result:

- production-affecting PRs still receive the browser gate
- docs-only PRs no longer pay for Playwright install/build/test
- post-merge production deploy remains covered by `build.yml`

### Staging checks

Observed current behavior before change:

- docs-only PRs ran the full staging integration build
- `npm run build` already ran Pagefind via `postbuild`
- explicit `npm run search:index` reran the same deterministic Pagefind build

Change:

- added `paths-ignore: docs/**` on `pull_request main`
- added `paths-ignore: docs/**` on `push staging`
- removed explicit `npm run search:index`

Result:

- PR integration verification remains intact for production-affecting changes
- docs-only PRs skip the full integration build
- one guaranteed redundant Pagefind pass is removed

### Build and Deploy

Observed current behavior before change:

- docs-only merges to `main` still triggered full production deploy
- `npm run build:no-og` already ran Pagefind via `postbuild:no-og`
- explicit `npm run search:index` reran the same deterministic Pagefind build
- weekly scheduled build still has a legitimate reason because external build-time inputs and caches can drift without repo commits

Change:

- added `paths-ignore: docs/**` on `push main`
- preserved weekly schedule
- preserved manual dispatch
- removed explicit `npm run search:index`

Result:

- production deploys still happen for real site-affecting merges
- docs-only merges no longer trigger unnecessary production deploys
- weekly refresh behavior remains intact
- one guaranteed redundant Pagefind pass is removed
