## 6. `course.lectures[]` rendering ownership

Reused unchanged from the 2013 precedent: the course page renders
`course.lectures[]` as a `<ul class="list-group">` of linked "Luento N:
Title" rows, where each `presentationPageUrl` points to the canonical
Presentation. Under COURSE-RELATION-UX-01 closure semantics this
page-local `lectures[].presentationPageUrl` list is authoritative for
the course page's own SSR rendering and does **not** duplicate the
canonical `(courseId, periodId)` backlink semantics. The Presentation
record still owns implementation membership through
`courseContexts[].periodId`.
